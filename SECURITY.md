# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public. Utilisez le signalement privé de GitHub :
onglet **Security** → **Report a vulnerability**. Une réponse est apportée sous
72 heures ouvrées.

## Mesures en place

L'audit de sécurité du projet, la réduction de la surface d'attaque et les preuves de
test sont décrits dans [docs/securite.md](docs/securite.md).
